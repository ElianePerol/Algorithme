# Affichage de Sapin de Noël avec Décorations Randomisées en Python

## Contexte du Projet
Ce dépôt contient un exercice Python consistant à afficher un sapin de Noël dans le terminal, avec une randomisation de la disposition des décorations (boules, guirlandes, etc.). 
Le but de cet exercice est d'appliquer des concepts de base en programmation Python, tels que les boucles, les fonctions et la génération de nombres aléatoires.

## Objectif de l'Exercice
L'objectif de cet exercice est de :
- Générer un sapin de Noël de taille variable à l'aide de boucles.
- Randomiser la disposition des décorations (boules, guirlandes, etc.) sur le sapin.
- Afficher le sapin dans la console avec des symboles ASCII.
